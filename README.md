# test-project

Mhm Hasan test project by Morsalin.

A **Node.js** app built with **TypeScript** and **Next.js** (App Router).

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Next.js (App Router)
- **Package manager:** npm

## Getting started

### Requirements

- Node.js 18 or later
- npm

### Install

```bash
npm install
```

### Scripts

Next.js scripts (`dev`, `build`, `start`, `lint`) will be available after the app is scaffolded.

```bash
npm run dev
npm run build
npm run start
npm run lint
```
